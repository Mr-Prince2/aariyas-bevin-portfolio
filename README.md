# Aariyas Bevin — Portfolio 創造

A minimalist, high-performance portfolio built with **React** and **GSAP**, inspired by Japanese aesthetics (*Wabi-sabi*, Washi paper, Sumi ink, and Shu-iro vermilion) and anime visual language. This project showcases the intersection of creative frontend engineering and AI/ML research.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+)
- **Animations:** GSAP (GreenSock), ScrollTrigger, Intersection Observer API
- **Design:** Japanese Typography (Shippori Mincho, Zen Kaku Gothic New), Glassmorphism, Washi-inspired UI/UX
- **Interactive:** Custom GSAP motion, Hanko seal stamp effects, Dynamic scrolling backgrounds

## ✨ Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
- **AI Project Showcases:** Highlighting work with YOLOv9, ResNet-50, FastAPI, and more.
- **Atmospheric Effects:** Smooth GSAP scroll reveals, parallax backgrounds, and subtle glassmorphism.
- **Categorized Skills:** Elegant Washi-styled skill layout with glowing interactive elements.
- **Themed UI:** Dark-mode interface styled with Sumi (Ink) backgrounds and Shu (Red) accents.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mr-Prince2/aariyas-bevin-portfolio.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd aariyas-bevin-portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   The site will open at `http://localhost:5173`.
