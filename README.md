# Aariyas Bevin — Portfolio 創造

A minimalist, high-performance portfolio built with **React** and **Framer Motion**, inspired by Japanese aesthetics (*Wabi-sabi*) and anime visual language. This project showcases the intersection of creative frontend engineering and AI/ML research.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, CSS3 (Modern Flexbox/Grid), JavaScript (ES6+)
- **Animations:** Intersection Observer API, CSS Keyframes, Framer Motion
- **Design:** Japanese Typography (Noto Serif JP), Anime-inspired UI/UX
- **Interactive:** Sakura Petal Engine (Custom JS/CSS Particle System)

## ✨ Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
- **AI Project Showcases:** Highlighting work with YOLOv9, ResNet-50, and FastAPI.
- **Atmospheric Effects:** Real-time falling Sakura petals and smooth scroll reveals.
- **Dynamic Skill Bars:** Animated proficiency tracking triggered on scroll.
- **Themed UI:** Dark-mode interface with Crimson (縁) and Gold (金) accents.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16.0.0 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Mr-Prince2/aariyas-bevin-portfolio.git](https://github.com/Mr-Prince2/aariyas-bevin-portfolio.git)

2. **Navigate to the project folder:**
  ```bash
  cd aariyas-bevin-portfolio
```
3. Install dependencies:
  ```bash
  npm install
```
4.Start the development server:
  ```Bash
  npm start
```
The site will open at http://localhost:3000.
